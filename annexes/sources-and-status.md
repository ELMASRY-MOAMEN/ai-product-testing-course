# Sources and status notes

## Internal methodological basis

This course is derived from the author's working notes on testing products that embed AI. It retains the confirmed terminology:

- **DoD:** Definition of Done;
- **DoT:** Definition of Trustworthy;
- **Hybrid:** separate DoD, DoT and UAT gates when user-facing.

The golden datasets and custom evaluators described in this course are applied designs. They are not presented as operational implementations.

## GitHub Copilot skill reference

GitHub documents agent skills as directories containing a file named `SKILL.md`, with YAML frontmatter including a `name` and `description`. Skills may also contain scripts and supporting resources referenced from the skill instructions.

- [Adding agent skills for GitHub Copilot](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/add-skills)
- [GitHub Copilot SDK custom skills](https://docs.github.com/en/copilot/how-tos/copilot-sdk/features/skills)
