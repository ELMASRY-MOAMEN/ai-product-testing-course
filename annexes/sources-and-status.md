## GitHub Copilot skill reference

GitHub documents agent skills as directories containing a file named `SKILL.md`, with YAML frontmatter including a `name` and `description`. Skills may also contain scripts and supporting resources referenced from the skill instructions.

- [Adding agent skills for GitHub Copilot](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/add-skills)
