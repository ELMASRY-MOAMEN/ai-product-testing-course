# Decisions required from the group

The discussion should close with explicit owners and decisions for:

- the first pilot User Story;
- dataset creation and review;
- annotation ownership;
- evaluator implementation and calibration;
- thresholds and veto approval;
- critical slices;
- storage, access control and retention;
- experiment and evidence tracking;
- the first GitHub Copilot skill to implement;
- the authorized acceptance decision.

## Decision table

| Decision | Owner | Status | Due date or next gate |
|---|---|---|---|
| Pilot User Story | To assign | Open | To define |
| Dataset owner | To assign | Open | To define |
| Business annotators | To assign | Open | To define |
| Evaluator owner | To assign | Open | To define |
| Threshold approvers | To assign | Open | Before first evaluation run |
| Storage and access pattern | To assign | Open | Before dataset operationalization |
| Skill implementation owner | To assign | Open | After pilot scope approval |

> **Takeaway:** Missing ownership is an evaluation blocker, not an implementation detail.
