# 5. Readiness assessment

Score against the checklist in `toolkit/readiness-checklist.md`, on **what exists**, not what is planned. An item that is "being organised" is not ticked.

## Classification

- [ ] The output nature is declared.
- [ ] Hybrid behaviour is decomposed into deterministic, probabilistic and UAT evidence.

## Requirements and risks

- [ ] Every acceptance criterion is testable.
- [ ] Critical business, security, privacy, compliance and operational risks are identified.
- [ ] Every scenario traces to a requirement or risk.

## Evaluation data

- [ ] The dataset has a name and version.
- [ ] Eligibility rules are explicit.
- [ ] References or rubrics are reviewed.
- [ ] Critical slices are labelled.
- [ ] Data handling is approved.

## Evaluators

- [ ] Every metric has a calculation method.
- [ ] Every evaluator has an owner and version.
- [ ] AI judges are calibrated against human-labelled examples.
- [ ] Exact checks use deterministic code where possible.

## Acceptance

- [ ] Thresholds were approved before execution.
- [ ] Critical slices have independent gates.
- [ ] Veto conditions are explicit.
- [ ] The authorized decision owner is identified.

## Reproducibility

- [ ] Code, model, prompt and tool versions are recorded.
- [ ] Execution parameters and repetitions are recorded.
- [ ] Case outputs and logs are preserved.
- [ ] The baseline comparison uses compatible evaluation assets.
