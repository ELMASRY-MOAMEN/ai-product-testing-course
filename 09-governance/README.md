# Module 09 — Governance

**Objective:** know exactly which decisions are yours, which are not, and how to say so under pressure without becoming the person the team routes around.

Everything up to here was craft. This module is about the moment the craft meets a release date, and it is the last thing before the capstone for a reason.

## Exercise

[Name the decision owner](exercises/name-the-decision-owner.md) — six situations from one release week — then compare with [the solution](exercises/solutions/name-the-decision-owner.md).

## Mastery criterion

Under realistic pressure — a release tonight, a senior person asking, a plausible shortcut on the table — you hold the boundary **and offer the shortest legitimate path**. Refusing without the second half is only half the skill, and it is the half that gets you excluded from the next decision.
